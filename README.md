
## Dataset

This project uses the Credit Card Fraud Detection
dataset provided by ULB.

Dataset Source:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

### How to Set Up the Dataset

1. Download the dataset from Kaggle.
2. Extract the downloaded ZIP file.
3. Create a folder named `data` in the project.
4. Place `creditcard.csv` inside the `data` folder.

Expected structure:

Banking-Fraud-Detection/
├── data/
│   └── creditcard.csv
├── app.py
├── main.py
└── requirements.txt

The dataset is excluded from GitHub because
it exceeds GitHub's 100 MB file size limit.
